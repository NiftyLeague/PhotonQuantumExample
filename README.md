# Photon Quantum Example — "Little Guys" sample

A small Unity + Photon Quantum sample. Licensed under Apache-2.0.

## Excluded commercial SDK

The **Photon Quantum / Photon Realtime SDK** (`quantum_unity/Assets/Photon/`)
is licensed under the Photon Engine EULA and is not redistributed in this
repository. Download the SDK from
[Photon](https://www.photonengine.com/quantum) and drop it back into
`quantum_unity/Assets/Photon/` to open the project; the sample scenes and
code then compile as before.

`PhotonServerSettings.asset` is included without an AppId — create a free
Quantum app in the Photon dashboard and paste your AppId there.

## Third-party assets retained

- KayKit Dungeon Pack, Kenney Assets, Sherbbs Particle Collection —
  free/CC0 packs, kept in place.
